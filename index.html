Caso de Estudio: Seguridad en OTEC Primavera

Descripción: Plataforma para la gestión de cursos y administración de alumnos en un entorno educativo.

Desafío principal: Garantizar la integridad de los datos y restringir el acceso a funcionalidades sensibles mediante una jerarquía de roles (Administrador y Alumno).

Solución técnica: Implementación de Spring Security con configuración de SecurityFilterChain y encriptación de credenciales mediante BCrypt.

Aprendizajes clave: Gestión de sesiones seguras, manejo de vulnerabilidades en backend y autorización basada en autoridades.

Justificación: Seleccioné este proyecto porque demuestra mi capacidad para manejar requisitos críticos de ciberseguridad corporativa.
